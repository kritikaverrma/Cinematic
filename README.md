# Cinematic 
1. Developed a Netflix-like OTT platform using MERN stack & Next.js for seamless on-demand and live video streaming.

## Features and Functionality

1. Implemented user authentication (JWT) with secure login, profile management, and subscription access control.
2. Designed an intuitive, mobile-responsive UI using Next.js, Tailwind CSS,Shadcn.
3. Built a real-time recommendation engine based on watch history and trending content using MongoDB Aggregations.
4. Enabled watchlist and favorites for personalized content tracking.
5. Integrated Razorpay payment gateway for subscriptions and premium content access.
6. Developed a custom admin dashboard for managing users, content uploads, and analytics (viewership stats, revenue tracking).
